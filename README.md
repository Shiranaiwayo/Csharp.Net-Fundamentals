# 🚀 C# & .NET Fundamentals Exercises

Welcome to my central repository for C# and .NET fundamental exercises, coding challenges, and daily practice. 

The purpose of this repository is to gather my continuous learning journey in one organized place. By structuring my exercises into a single monorepo, I keep my GitHub profile clean while maintaining a consistent, daily coding habit.

## 📂 Repository Structure

Each directory represents a specific module or core topic from my C# and .NET studies:

*   **`01-loops-and-arrays/`** – Practice with `for`, `foreach`, and `while` loops alongside basic array manipulation.
*   **`02-methods-and-functions/`** – Creating reusable code blocks, understanding parameters (`out`/`ref`), and return types.
*   **`03-oop-principles/`** – Object-Oriented Programming core concepts: Classes, Objects, Inheritance, Polymorphism, and Encapsulation.
*   **`04-interfaces-and-abstract-classes/`** – Implementing interfaces, abstract classes, and achieving loose coupling in code.
*   **`05-dotnet-advanced/`** – Deep dive into .NET specific features like LINQ, File I/O, Exception Handling, and asynchronous programming.

## 🛠️ Tech Stack & Skills Covered

*   **Language & Framework:** C#, .NET Core / .NET 8
*   **Version Control:** Git & GitHub (Structured branching, meaningful commits)
*   **Concepts:** OOP (Object-Oriented Programming), Clean Code, and Debugging.

## 📈 Activity & Goals

My main goal with this repository is **consistency**. Inside each folder, you will find incremental updates showing my daily progression. I aim to write, test, and commit code regularly to continuously sharpen my development skills.

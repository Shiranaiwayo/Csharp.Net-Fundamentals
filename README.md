# 🎮 C# Console Guessing Game

A fun, interactive console-based guessing game built while learning the fundamentals of C# programming. The application generates a secret number, and the player has to guess it based on logical hints.

## 🚀 Key Logic & Features
- **Random Number Generation:** Uses the C# `Random` class to ensure a unique target number every game.
- **Game Loops:** Employs conditional loops to keep the game active until the player guesses correctly or runs out of tries.
- **Interactive Feedback:** Provides real-time "too high" or "too low" hints to guide the user's next input.
- **Input Filtering:** Handles basic validation to ensure the player enters valid numbers.

## 🛠️ Built With
- **Language:** C#
- **Framework:** .NET (Console Application)

## 📦 How to Run the Project Locally

Ensure you have the [.NET SDK](https://microsoft.com) installed on your machine.

1. **Clone this repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project folder:**
   ```bash
   cd Guessing-game-csharp/"Guessing game"
   ```

3. **Run the game:**
   ```bash
   dotnet run
   ```

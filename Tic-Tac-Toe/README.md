# 🎮 C# Tic-Tac-Toe

A simple two-player console-based Tic-Tac-Toe game where players take turns choosing squares from 1–9. The project focuses on methods, arrays, input validation, game logic, and loops.

## 🚀 Key Logic & Features

* **Game Board:** Uses a `string[]` to store the 9 board positions.
* **Methods:** Separates game logic into methods such as `DisplayBoard()`, `GetValidMove()`, `CheckWinner()`, and `CheckDraw()`.
* **Input Validation:** Ensures the player enters a valid number between 1 and 9.
* **Move Validation:** Prevents players from choosing an occupied square.
* **Win & Draw Detection:** Checks for winning combinations and detects when the board is full.
* **Player Switching:** Alternates between Player 1 (`X`) and Player 2 (`O`).
* **Console Display:** Dynamically displays available squares, `X`, and `O`.

## 🛠️ Built With

* **Language:** C#
* **Framework:** .NET (Console Application)
* **IDE:** Visual Studio Community

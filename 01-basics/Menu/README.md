# 📋 C# Console Menu System

An interactive console-based navigation system built while mastering C# and .NET structure. This project focuses on building structured, scalable menus using switch-case logic and robust choice validation.

## 🚀 What I Practiced
- **Dynamic Navigation:** Built an interactive command-line interface allowing users to navigate cleanly between different project tasks or modules.
- **Switch-Case Architecture:** Structured menu handling effectively using optimized `switch` blocks to replace cluttered if-else statements.
- **Fail-Safe Processing:** Wrapped input collection in loops to handle invalid menu selections smoothly without breaking execution.
- **Clean Interface Execution:** Combined console clearing mechanics to simulate multi-page system transitions right inside the terminal.

## 🛠️ Built With
- **Language:** C#
- **Framework:** .NET 8.0 / .NET 9.0 (Console Application)

## 📦 How to Run the Project Locally

To test this menu system on your machine, ensure you have the [.NET SDK](https://microsoft.com) installed.

1. **Clone this repository:**
   ```bash
   git clone https://github.com
   cd Menu
   ```

2. **Build the project:**
   ```bash
   dotnet build
   ```

3. **Start the application:**
   ```bash
   dotnet run
   ```
